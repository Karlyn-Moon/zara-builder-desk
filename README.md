# Zara Builder Desk

一个基于公开资料整理的 Zara Builder Desk：

- 浏览 Zara Zhang（`zarazhangrui`）公开 GitHub 产品
- 查看公开原话、模式归纳与小红书公开笔记主题
- 用证据边界清晰的思考导师拆解、反证和推进产品想法

> 这是基于公开作品的产品思考训练器，不是 Zara 的数字分身。小红书正文在未登录状态下不可读取，因此只使用公开主页信息、可见标题和已核对的来源。

## 本地运行

```bash
npm install
npm run dev
```

## 验证

```bash
npm test
npm run build
```

## GitHub Pages

仓库中的 `.github/workflows/deploy-pages.yml` 会在 `main` 分支更新后自动构建并发布到 GitHub Pages。首次创建仓库后，在 GitHub 的 **Settings → Pages** 将发布来源设为 **GitHub Actions**；工作流完成后即可从 Actions 的部署记录打开站点。
